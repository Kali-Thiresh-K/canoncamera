# Canon EOS R1 Masterclass — AI Coding Guidelines

This repository contains the interactive showcase website for the Canon EOS R1 Flagship camera.

## Tech Stack & Architecture
- **Framework**: React 19 + TanStack Start / Vite
- **Styling**: TailwindCSS v4 + Custom Vanilla CSS Design System
- **Hero Animation**: HTML5 2D Canvas sequence with `createImageBitmap` off-main-thread decoding, hover-based wheel scrub, and lerp-free instant frame updates.
- **Icons & UI**: Lucide React + Radix UI primitives
